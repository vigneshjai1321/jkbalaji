# Shared brand assets (JK Balaji monorepo)

Canonical copies of **cross-app brand icons** live here. Each Next.js app still serves its own `public/icons/` at deploy time (no runtime coupling).

- `brand/icons/` — SVG favicon-style marks (`jkbalaji.svg`, `cheyyar.svg`, `admin.svg`)
- `review/` — archived files removed from an app when their purpose belongs elsewhere (see `backups/assets-org-20261013/ORGANIZATION_REPORT.md`)

Marketing photos belong only under:

- `apps/real-estate-web/public/assets/images/` — properties, banners
- `apps/jewellery-web/public/assets/images/` — products

Do not copy plot or promoter photos into the jewellery app, or product photos into the real estate app.
